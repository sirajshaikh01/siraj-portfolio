## ⚙️ Setup and Usage

To run the portfolio locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/sirajshaikh01/siraj-portfolio.git
   ```

2. Navigate to the project directory:

   ```bash
   cd siraj-portfolio
   ```

3. Open `index.html` in your browser.
